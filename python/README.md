# Python and Jupyter Notebook

This directory contains the Jupyter Notebooks used for Python-based data acquisition, exploratory data analysis, data quality assessment, and data cleaning and preparation for the Strait of Hormuz Supply Chain Analytics project.

## Planned Notebooks

1. `01_data_acquisition.ipynb` — Collect data from selected sources.
2. `02_exploratory_data_analysis.ipynb` — Explore data distributions, trends, and patterns.
3. `03_data_quality_assessment.ipynb` — Assess missing values, duplicates, invalid records, and inconsistencies.
4. `04_data_cleaning_and_preparation.ipynb` — Clean and prepare datasets for analysis.

The notebooks will be created and executed using Jupyter Notebook and Python.
