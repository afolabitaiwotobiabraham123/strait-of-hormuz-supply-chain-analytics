# Power BI Dashboard

This directory contains the Power BI dashboard and supporting visual materials for the Strait of Hormuz Supply Chain Analytics project.

The dashboard will present data-supported insights into maritime traffic, petroleum transportation flows, disruption patterns, and relevant supply chain performance indicators.

## Directory Structure

- `dashboard/` — Power BI report files (`.pbix`).
- `screenshots/` — Images showing the completed dashboard and key visualizations.

Dashboard metrics and conclusions will be based on the available data and documented KPI definitions.
