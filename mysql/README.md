# MySQL Analysis

This directory contains SQL scripts for storing, querying, and analyzing prepared datasets for the Strait of Hormuz Supply Chain Analytics project.

## Planned SQL Scripts

1. `01_database_setup.sql` — Create the database and required tables.
2. `02_maritime_traffic_analysis.sql` — Analyze vessel traffic and transit patterns.
3. `03_petroleum_flow_analysis.sql` — Analyze available petroleum transportation data.
4. `04_supply_chain_kpi_calculations.sql` — Calculate supported supply chain performance indicators.
5. `05_disruption_period_comparison.sql` — Compare baseline and disruption periods when the data supports the comparison.

All findings will be based on available data. SQL analyses will distinguish vessel traffic from petroleum volumes and will not assume that one directly measures the other.
