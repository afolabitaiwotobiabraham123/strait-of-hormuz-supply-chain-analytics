# Project Documentation

This directory contains technical documentation for the Strait of Hormuz Supply Chain Analytics project.

## Planned Documents

1. `data_sources.md` — Records the selected data sources, source URLs, collection dates, coverage, and limitations.
2. `data_dictionary.md` — Defines dataset columns, data types, meanings, and units of measurement.
3. `kpi_definitions.md` — Documents KPI formulas, calculation methods, units, and interpretation.

Documentation will be updated as the data sources and analytical methods are verified.

Metrics will only be defined for indicators that can be supported by the available data.
